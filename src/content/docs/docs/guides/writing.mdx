## frontmatter

| 字段          | 必填 | 说明                       |
| ------------- | ---- | -------------------------- |
| `title`       | 是   | 页面标题，同时用于侧边栏   |
| `description` | 是   | 一句话简介，用于搜索与分享 |
| `sidebar.order` | 否 | 同组内的排序，数字越小越靠前 |
| `draft`       | 否   | `true` 时不发布            |

## 正文约定

- 一级标题不用写，`title` 就是页面大标题；正文从二级标题开始
- 代码块标明语言，命令给出可直接复制的完整形式
- 图片放在文章同目录下相对引用，文件名用英文短横线命名
- 一篇文档只解决一件事，太长就拆成同组多篇，用侧边栏串起来
